T-Bone — Steakhouse Racer
========================
A T-bone steak mascot kart for SuperTuxKart. The driver is the logo itself,
extruded with arms to steer. Kart is dark espresso with brass stripes,
license plate T-BONE on rear.

Designer: Arena.ai (Chicago, Oct 2026) for user request
License: CC-BY-SA 4.0
Blend source: tbone_source.blend (Blender 4.3.2)

Install: copy tbone/ folder to ~/.local/share/supertuxkart/addons/karts/
